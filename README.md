# Kartik Sanjay Bhamare — Portfolio

Personal portfolio website built with React + Vite, showcasing my background as an MCA student, AI & Machine Learning enthusiast, and Python developer.

## Sections

- Home
- About
- Education & Experience (includes Certificates and Achievements)
- Projects
- Skills
- Contact

## Tech Stack

- React 19 + Vite
- Tailwind CSS
- Framer Motion
- EmailJS (contact form)

## Getting Started

```bash
npm install
npm run dev
```

Then open the local URL printed in the terminal.

## Build

```bash
npm run build
npm run preview
```

## Note on the Contact Form

The contact form uses [EmailJS](https://www.emailjs.com/). Update the `service_id`, `template_id`, and public key in `src/components/Contacts.jsx` with your own EmailJS credentials so submitted messages are delivered to your inbox.
